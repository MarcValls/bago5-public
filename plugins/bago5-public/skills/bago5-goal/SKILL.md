# Definir y seguir un objetivo

Conserva el enunciado del usuario, quién puede aceptarlo, el proyecto, los límites y la evidencia necesaria para comprobar el resultado. Para cada criterio escribe una pregunta que pueda responderse con un resultado observable. Identifica qué falta para empezar y qué se puede ejecutar ya.

Si existe un objetivo previo, relee su identificador y revisión. Registra los cambios de alcance como una revisión nueva. Usa un único registro como autoridad del objetivo. Activa un controlador de objetivos o persiste la ficha solo cuando el host lo permita y la tarea lo autorice.

Relaciona cada acción con un criterio. Marca una acción pendiente con su dependencia o con la decisión que debe resolverla. Si hay varias fases, usa [planificación por fases](../bago5-phased/SKILL.md). Entrega la ficha de objetivo, la revisión comprobada y los resultados por criterio. Reclama cierre cuando todos los criterios obligatorios tengan evidencia aplicable.
