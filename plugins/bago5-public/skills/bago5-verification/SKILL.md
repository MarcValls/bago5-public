# Contrastar afirmaciones contra una candidata exacta y emitir dictamen

Identifica candidata, base anterior, aceptación y límites del entorno. Ejecuta las pruebas pertinentes de comportamiento positivo y negativo, regresión, accesibilidad o contrato. Registra entrada, resultado y evidencia localizable para cada afirmación.

Separa inspección, simulación, prueba real, revisión propia y revisión independiente. Si falta el destino, marca esa comprobación `NOT_RUN`. El dictamen debe indicar hechos observados, criterio satisfecho o pendiente e impacto de los fallos. Conserva la candidata para que el resultado sea reproducible.
