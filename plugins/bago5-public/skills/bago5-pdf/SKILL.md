# Maquetar y comprobar PDF

Identifica fuentes editables, formato de página, idioma, audiencia y entrega requerida. Mantén una copia de las fuentes. Define jerarquía, márgenes, tipografía disponible y reglas de salto antes de producir el PDF. Conserva texto seleccionable y etiquetas de accesibilidad cuando el exportador las ofrezca.

Genera el PDF y vuelve a abrirlo con un lector independiente. Contrasta el número y orden de páginas; extrae texto para comprobar títulos, acentos y contenido imprescindible. Renderiza las páginas y revisa recortes, sustitución de caracteres, contraste, pies, tablas y enlaces. Para documentos extensos inspecciona todas las páginas mediante miniaturas y a tamaño real las de diseño complejo.

Entrega el PDF y las fuentes si se solicitaron, con las verificaciones realizadas y su alcance. Un resultado de extracción de texto no acredita la maquetación visual.
