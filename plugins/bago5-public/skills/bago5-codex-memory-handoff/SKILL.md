# Entregar contexto de memoria a otra sesión

1. Identifica proyecto, memoria, modo autorizado, revisión del contenido y motivo del relevo. Elige solo los elementos necesarios para que el receptor continúe.

2. Prepara un mensaje con objetivo, trabajo hecho, decisiones, bloqueos, próximo paso y referencias que el receptor pueda resolver. Evita copiar credenciales, historiales o contenido personal prescindible.

3. Al recibirlo, consulta la identidad efectiva del conector, el alcance de acceso y una referencia acordada. Para un relevo de lectura basta comprobar lectura. Para una escritura autorizada, relee el registro creado y contrasta su revisión.

## Criterio de cierre

Distingue mensaje preparado, recibido y contexto recuperado. Si la sesión carece de acceso, lleva el contexto mínimo autorizado al mensaje y deja la lectura o escritura remota NOT_RUN.
