# Auditar flujos de interfaz y corregir barreras de interacción y accesibilidad

Recorre la tarea principal como usuario. Comprueba jerarquía visual, etiquetas, orden de foco, teclado, lector de pantalla, contraste y pantallas estrechas. Recorre también carga, vacío, error y recuperación. Usa estados y datos sintéticos que representen cada recorrido.

Vincula cada incidencia con un control o una transición concreta. Aplica el sistema visual existente y conserva las gestiones que dependen del control que cambias. Mide el contraste sobre colores realmente renderizados. Verifica de nuevo el recorrido completo en el navegador con la candidata final.
