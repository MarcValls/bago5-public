# Reparar un defecto demostrado y comprobar la regresión

Registra la versión afectada, el caso que falla, el resultado esperado y la evidencia del fallo. Conserva el original y prepara una candidata con la corrección mínima y una vía de recuperación.

Repite el caso inicial y comprueba un caso válido, las entradas límite y los contratos afectados. Identifica diferencias y causas pendientes. Presenta el resultado con la candidata probada y el alcance del permiso de reparación. Publicar, desplegar o modificar datos persistentes requiere autorización para ese efecto.
