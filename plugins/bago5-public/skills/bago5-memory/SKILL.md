# Coordinar el guardado de memoria

Distingue lo que el usuario quiere conservar: decisión, hecho comprobado, preferencia o propuesta. Redacta un registro breve con procedencia, alcance y estado. Para una petición de continuidad, identifica el proyecto activo y lee únicamente los antecedentes pertinentes.

Resuelve el destino y el modo de lectura o escritura elegido. Si hay varios almacenes posibles y el contexto no decide, aclara el destino. Comprueba por el canal autenticado que puedes operar sobre la memoria y el proyecto concretos. Conserva las exclusiones del usuario.

Usa [Memoria Viva](../bago5-memoria-viva/SKILL.md) cuando sea el almacén seleccionado. Tras una escritura, vuelve a leer y coteja el contenido, el ID y la revisión. Si solo preparaste un texto o una propuesta de guardado, identifica ese estado. Evita almacenar una conversación completa cuando basta una decisión.
