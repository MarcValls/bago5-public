# Crear un repositorio GitHub

1. Obtén del encargo el propietario, nombre, visibilidad y si debe iniciarse con archivos. Comprueba el usuario autenticado y el acceso efectivo al propietario mediante la herramienta GitHub disponible. Evita imprimir credenciales.
2. Consulta el nombre exacto en el espacio de destino. Si ya existe, comprueba su identidad y conserva su estado. Si la visibilidad solicitada o los permisos son ambiguos, resuelve esa condición antes de crear.
3. Ejecuta una sola creación con los parámetros acordados. Ante una interrupción, consulta primero el destino exacto antes de repetir. La creación no incluye transferir, borrar, publicar contenido o cambiar la protección de ramas.
4. Relee el repositorio con otra consulta. Entrega su URL, ID, nombre completo y visibilidad observados. Distingue creación ejecutada, repo preexistente y creación pendiente por falta de herramienta.
