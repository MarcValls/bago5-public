# Desarrollar una aplicación o un juego

1. Identifica el punto de entrada, la versión de motor o framework, los dispositivos objetivo y las herramientas disponibles. Reproduce un recorrido de referencia y especifica el resultado visible solicitado.

2. Construye un tramo completo. Para un juego sigue entrada de usuario, transición de estado, resultado en la escena y reinicio. Para una aplicación sigue entrada, validación, persistencia y retorno. Conserva contratos y recursos usados por las demás pantallas o niveles.

3. Ejecuta la compilación del objetivo y recorre el caso normal y un fallo recuperable. Cuando haya estado persistente comprueba una segunda apertura con los valores guardados.

## Criterio de cierre

Entrega la candidata, la ruta para repetir la interacción, plataforma probada y límites. Si falta motor, simulador o dispositivo, informa qué parte se comprobó en fuente y qué prueba queda NOT_RUN.
