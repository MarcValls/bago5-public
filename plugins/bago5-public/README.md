# BAGO5 Público

Edición en español para trabajar en proyectos con 59 habilidades de planificación, desarrollo, memoria y verificación. Es una distribución de habilidades que se instala por separado de BAGO5 Gobernado. Elige una tarea y empieza con `$bago5-govern`.

## Instalar en Codex

Con Codex CLI y Git disponibles, ejecuta estos comandos en tu terminal:

```sh
codex plugin marketplace add MarcValls/bago5-public
codex plugin add bago5-public@bago5-public-tools
```

Abre una sesión nueva para utilizar el plugin. Si tienes varias ediciones instaladas, selecciona la habilidad cualificada del plugin `bago5-public`.

## Probarlo

- «Usa $bago5-goal para convertir este encargo en criterios de aceptación que pueda comprobar».
- «Usa $bago5-workflow para elegir qué habilidades hacen falta para reparar esta interfaz».
- «Usa $bago5-final-verifier para contrastar lo entregado con esos criterios. Enumera las pruebas que has ejecutado».

La edición incluye instrucciones portables y utilidades locales opcionales. Las habilidades de memoria utilizan el servicio que configures por separado en tu cliente. Antes de leer o escribir, comprueba la identidad de la memoria, el proyecto y sus permisos. La instalación por sí sola no configura servicios, concede acceso a cuentas ni inicia observadores.

Puedes descargar el [ZIP de la edición pública](https://github.com/MarcValls/bago5-public/releases/latest/download/bago5-public.zip) y su [SHA-256](https://github.com/MarcValls/bago5-public/releases/latest/download/bago5-public.zip.sha256).
