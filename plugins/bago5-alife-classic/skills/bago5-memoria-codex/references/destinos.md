# Descubrimiento de destinos

No hay endpoint personal predeterminado. Descubrir conectores expuestos y comprobar identidad y permisos mediante lecturas autorizadas. Obtener el endpoint MCP y recurso OAuth de configuración vigente del servicio seleccionado; una URL del sitio no acredita su endpoint MCP. No copiar las ubicaciones personales de MYTHOS ni del autor. Si falta identidad o endpoint, declarar BLOQUEADO y pedir el dato concreto. Separar servicios de memoria de sus proyectos internos.
