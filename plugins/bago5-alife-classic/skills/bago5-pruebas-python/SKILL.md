name: bago5-pruebas-python
description: Ejecutar y recuperar una campaña de pruebas Python.
---

Selecciona el entorno y las pruebas que ejercitan el cambio. Identifica la versión de Python y la candidata. Si tienes un ejecutor autorizado, usa el comando de pruebas del proyecto y conserva salida, código de retorno y fallos. Si la ejecución corresponde a otro cliente, entrega el comando y el criterio de éxito. Solo da una prueba por superada con el resultado de esa ejecución.

En Codex, aplica el [formato de respuesta de BAGO](../bago5/SKILL.md#respuestas-en-codex) al comunicar el resultado.
