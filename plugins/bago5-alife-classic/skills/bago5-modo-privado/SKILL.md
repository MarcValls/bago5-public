# Autenticación y datos privados

La autenticación se completa en la pantalla oficial del servicio. Cuando se necesite iniciar sesión o dar consentimiento, entrega ese paso a la persona. El usuario vuelve al chat cuando haya terminado. Comprueba entonces la identidad y los permisos que devuelve el servicio.

Conserva únicamente el resultado necesario para continuar. No solicites contraseñas, códigos o enlaces de acceso en una conversación. Si el cliente carece de una superficie privada adecuada, deja esa operación pendiente y ofrece el enlace oficial. Para ALIFE, la cuenta se abre en https://alifememories.com/memoria-viva.

En Codex, aplica el [formato de respuesta de BAGO](../bago5/SKILL.md#respuestas-en-codex) al comunicar el resultado.
