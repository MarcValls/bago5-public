# Binding de instalación 0.3.0

`docs/PROTOCOL.json` describe el protocolo histórico COG-REPAIR-002. El runtime ejecutor actual
se obtiene de PACKAGE_IDENTITY.json y queda fijado en CONFIG.json, INPUT_FREEZE y el ledger.
La copia histórica de ConfigManager sigue siendo el objetivo de la regresión integrada. El módulo
instalado corregido se prueba por separado con los mismos doce criterios y el consumidor nativo.
No se ejecuta una segunda copia RC2 del motor. La misma sesión, espiral, gateway y memoria proceden
del payload identificado. Todos los paths de trabajo y estado están fuera de la instalación.
