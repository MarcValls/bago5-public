# STANDARD-FIRST — apps and games

Before adding technology, decide `REUSE → ADAPT → EXTEND → INVENT`.
Document requirements, existing in-project implementations, candidate standards,
compatibility, dependencies, negative tests and proof. Do not install frameworks or
services by default. Framework choice does not waive preservation of old capabilities.
MCP / OpenAPI / JSON Schema / OpenTelemetry are references only when needed,
not required runtime dependencies of this skill.
