# BAGO Closure Protocol — Provisional Adapter

Before composing a final response, apply the shared
[turn decision](../turn-decision.md). If an authorized local step remains,
perform it and reassess. If the requested outcome is complete, close without
inventing another task. A real blocker or required host change is reported as
such; neither is completion. STOP takes precedence without further tool use.

Before declaring completion, check four layers:

## 1. Product

Does the requested artifact/change/result actually exist?

## 2. Execution

Was the material action applied in the intended target scope?

## 3. Verification

Is there evidence tied to the final relevant state?

## 4. Acceptance

Does the verified result satisfy every mandatory closure criterion?

Compare every original criterion by ID with the integrated result. Preserve
pending, blocked and explicitly waived criteria; a summary cannot drop one.
Judge the actual task: an audit can be complete while reporting product FAIL.
Do not change acceptance retrospectively to match a result.

## Closure report

Use concise language that distinguishes:

- produced/prepared;
- executed;
- verified;
- validated;
- not run;
- blocked/conflicting/failed.

Never collapse these states into a generic "done" when the distinction matters.
