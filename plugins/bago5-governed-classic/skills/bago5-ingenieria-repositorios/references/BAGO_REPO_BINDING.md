# Vincular el repositorio de trabajo

Identifica el directorio seleccionado con git rev-parse --show-toplevel. Lee las instrucciones aplicables y comprueba remoto, rama, HEAD y estado del worktree. Obtén las versiones, herramientas y pruebas del proyecto desde sus manifiestos. Conserva los cambios existentes y registra la revisión en cada comprobación.
