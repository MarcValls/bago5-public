# Procedencia técnica

Consultado el 15/11/2026:
- KeePassXC User Guide: https://keepassxc.org/docs/KeePassXC_UserGuide
  Documenta GUI, opciones de línea de comandos, bloqueo, variables e integraciones.
- KeePassXC Verifying Signatures: https://keepassxc.org/verifying-signatures/
  Diferencia autenticidad de firma y simple comprobación de hash; firma MSI no equivale
  a comprobar aquí una instalación concreta.
- Fuente del plugin: Plugin Creator, BAGO5 0.4.20,
  referencia-de-origen, get_plugin_files.

No se fija una versión KeePassXC instalada ni un certificado de firmante de memoria.
Los pins deben provenir de comprobación local legítima. No se afirma que las medidas
antiscaptura de KeePassXC detengan todos los canales del host.
